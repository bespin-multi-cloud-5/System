# 06 .NET 워크로드와 마이그레이션 / 02 Azure 마이그레이션

온프레미스 Windows Server 자산을 Azure와 잇는 네 가지 도구를 인식 수준으로 다룬다. 이론 전용 섹션이며, 실제 설정·마이그레이션 실습은 Azure 시리즈에서 다룬다.

## What you will learn

- Azure Migrate: 검색·평가·이전 허브 (Hyper-V/VMware/물리)
- Azure Site Recovery: 재해 복구(DR), 복제 후 Azure로 페일오버
- Azure Arc: 이전하지 않고 제자리에서 Azure 관리 평면으로 관리 (하이브리드)
- Azure Hybrid Benefit: 기존 Windows Server 라이선스 재사용으로 컴퓨트 비용 최대 40%+ 절감

## Examples

- 이론 전용 (실습 없음). Hyper-V VM이 Azure Migrate로 이전되는 출발점, 실제 설정은 Azure 시리즈.
