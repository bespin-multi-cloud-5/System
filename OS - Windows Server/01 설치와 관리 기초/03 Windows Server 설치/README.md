# 01 설치와 관리 기초 / 03 Windows Server 설치

VirtualBox에 Windows Server 2022를 Desktop Experience로 설치하고 첫 로그인까지 완료한다. 이후 모든 Lab의 토대가 되는 `winserver-vm`을 준비한다.

## What you will learn

- Windows Server 2022 시스템 요구사항 (Desktop Experience는 메모리 2 GB 이상)
- VirtualBox VM 생성 (2코어 / 4 GB / 60 GB 동적 할당)
- Setup 마법사로 Desktop Experience 설치 (에디션·옵션 선택, Custom 설치)
- Administrator 비밀번호 설정과 첫 로그인, Server Manager 자동 실행
- Rocky Linux의 Anaconda 설치와의 대응 (마법사·파티션·관리자 계정·로그인)

## Examples

- `lab01` → VirtualBox VM 생성부터 Windows Server 2022 설치, 첫 로그인, Server Manager 확인까지
