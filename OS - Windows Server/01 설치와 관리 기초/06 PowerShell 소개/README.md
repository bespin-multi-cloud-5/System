# 01 설치와 관리 기초 / 06 PowerShell 소개

이 과목의 주력 도구인 PowerShell의 기본을 익힌다. Verb-Noun 명명 규칙, 객체 파이프라인, 탐색 도구를 다루며, Linux의 bash와 비교해 "텍스트 셸 vs 객체 셸"의 차이를 잡는다.

## What you will learn

- PowerShell의 정체: .NET 기반 셸이자 스크립팅 언어. Windows PowerShell 5.1과 PowerShell 7의 공존
- Verb-Noun 명명 규칙과 승인된 동사(`Get-Verb`), 별칭
- 객체 파이프라인: bash(텍스트)와 PowerShell(.NET 객체)의 차이
- 탐색 3종: `Get-Help`(man), `Get-Command`(which), `Get-Member`(객체 속성 탐색)
- (실전 이어짐) 파일·레지스트리·환경변수를 PSDrive로 다루는 실습은 다음 챕터 PowerShell과 PSDrive에서
