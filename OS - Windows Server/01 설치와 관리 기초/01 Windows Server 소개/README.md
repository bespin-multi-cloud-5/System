# 01 설치와 관리 기초 / 01 Windows Server 소개

Windows Server가 어떤 OS이고 어떻게 지금의 모습이 되었는지 짚는 시리즈 진입 섹션이다. 역사를 따라가면 이 과목에서 배울 것들(Active Directory, Hyper-V, Azure 연결)이 언제 왜 등장했는지 드러난다. 이 역사가 곧 이 과목의 목차다.

## What you will learn

- Windows Server의 정체: 기업용 서버 OS이며, 데스크톱 Windows와 커널을 공유하되 역할(Role) 중심으로 무중단 운영한다
- Rocky Linux와 같은 자리이되, 차이는 상용 라이선스와 통합 생태계(AD·.NET·Hyper-V·Azure)에 있다
- 기능 누적의 역사: 2000 Active Directory → 2008 Hyper-V·Server Core → 2012 Storage Spaces → 2016 컨테이너·WSL → 2022 Azure Arc → 2025 핫패칭
- 이 역사가 곧 이 과목의 목차라는 것 (AD→신원 관리, Hyper-V·Server Core→가상화와 "GUI→CLI" 서사, Azure Arc→클라우드 연결)
- 실습 기준은 2022(LTSC), 2025가 더한 방향("온프레미스도 클라우드처럼")은 인식 수준
