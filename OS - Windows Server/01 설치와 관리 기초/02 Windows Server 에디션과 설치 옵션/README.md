# 01 설치와 관리 기초 / 02 Windows Server 에디션과 설치 옵션

Windows Server를 설치하기 전에 결정해야 할 에디션(Standard/Datacenter)과 설치 옵션(Desktop Experience/Server Core), 라이선스 모델을 다룬다. 이 과목이 Desktop Experience로 시작하는 이유를 잡는 이론 섹션이다.

## What you will learn

- Standard와 Datacenter 에디션의 차이 (가상화 권한이 핵심, S2D·SDN·Shielded VMs는 Datacenter 전용)
- Desktop Experience와 Server Core 설치 옵션, 그리고 설치 후 상호 전환이 불가능하다는 제약
- Rocky Linux의 Minimal 설치 ↔ Server Core, GUI 설치 ↔ Desktop Experience 대응
- 코어 기반 라이선스, CAL, Azure Hybrid Benefit (인식 수준)
- 이 과목이 Desktop Experience로 시작하는 학습 설계상의 이유 (GUI에서 출발해 PowerShell로)
