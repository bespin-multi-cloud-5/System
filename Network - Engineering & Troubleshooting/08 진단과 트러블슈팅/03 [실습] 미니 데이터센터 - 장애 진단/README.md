# 08 진단과 트러블슈팅 / 03 [실습] 미니 데이터센터: 장애 진단

04~07장에서 누적 구축한 미니 데이터센터에 실제로 고장을 내고 Bottom-Up으로 진단한다. 같은 증상("웹서버에 접속이 안 된다")이지만 원인이 다른 시나리오 4개를 다룬다. 미니 데이터센터 서사의 '고치다' 단계다.

## What you will learn

- 같은 증상에 대해 계층별 진단으로 원인 특정
- Connection refused vs Connection timed out의 차이 체감
- tcpdump로 장애의 증거 수집 (SYN→RST vs SYN→무응답)
- 진단 과정 기록 습관 (Bottom-Up 진단 양식)
- 4개 시나리오: B(L7 Nginx 중지) / A(L4 방화벽 차단) / C(L3 경로 삭제) / D(L3 IP Forwarding 비활성화)

## 미니 데이터센터 진행

구축(04.03~07.04)된 미니 데이터센터를 진단한다. 인프라를 추가하지 않는 '고치다' 단계다.

```
  ✓ 04.03 네트워크 설계와 구현
  ✓ 04.05 라우팅
  ✓ 07.02 방화벽
  ✓ 07.04 NAT
  ▶ 08.03 장애 진단 ← 현재 (구축된 환경을 진단)
    09.02 완성
```
