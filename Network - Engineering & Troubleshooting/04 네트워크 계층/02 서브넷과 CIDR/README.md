# 04 네트워크 계층 / 02 서브넷과 CIDR

서브넷 분할의 이유, 서브넷 마스크, CIDR 표기, 주소 계산, 서브넷 설계를 다룬다. 이론 전용. 실습은 04.03 [실습] 미니 데이터센터: 네트워크 설계와 구현에서 수행.

## What you will learn

- 서브넷: 네트워크를 작은 단위로 분할 (브로드캐스트 범위, 보안, 관리)
- 서브넷 마스크: IP AND 마스크 = 네트워크 주소. 네트워크부/호스트부 경계
- CIDR: /N 표기, 클래스 대체, 자유로운 경계 설정
- 주소 계산: 네트워크 주소, 브로드캐스트 주소, 호스트 수 = 2^(32-N) - 2
- 서브넷 크기: /24(254), /26(62), /28(14), /30(2)
- 서브넷 설계: 미니 데이터센터 주소 계획 (subnet-pub + subnet-priv)
