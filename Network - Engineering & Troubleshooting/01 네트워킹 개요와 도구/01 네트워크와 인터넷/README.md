# 01 네트워킹 개요와 도구 / 01 네트워크와 인터넷

네트워크의 정의, 네트워킹(데이터 교환), 패킷 구조, 인터넷의 성장 과정을 다룬다.

## What you will learn

- 네트워크(연결) → 네트워킹(데이터 교환) → 교환에 필요한 것(매체, 주소, 프로토콜)
- 패킷: Header(제어 정보) + Payload(데이터). 프로토콜 = Header의 규칙
- 클라이언트-서버 모델: 요청-응답 패턴
- internet(소문자) vs Internet(대문자, TCP/IP): 과거 독립 프로토콜 스택과 TCP/IP의 성장
- 인터넷 구조: ISP 3-Tier 계층, Peering vs Transit, IXP
- 패킷 교환 vs 회선 교환
