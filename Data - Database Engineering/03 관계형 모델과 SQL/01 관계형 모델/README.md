# 03 관계형 모델과 SQL / 01 관계형 모델

관계형 모델의 세 요소(릴레이션·키·무결성 제약)를 employees 데이터베이스로 보고, 구조화가 왜 JOIN을 필수로 만드는지 짚는다.

## What you will learn

- 릴레이션·튜플·속성·도메인 (E.F. Codd의 관계형 모델)
- 키: 기본키(Primary Key)·후보키(Candidate Key)·외래키(Foreign Key)
- 무결성 제약: 엔티티·참조·도메인
- employees 6테이블의 관계 구조(`emp_no`·`dept_no` 연결, `dept_emp` junction table)와 구조화 → JOIN의 관계
