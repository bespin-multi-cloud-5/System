# 02 MariaDB 설치와 구성 / 01 MariaDB 설치

MariaDB가 무엇인지 보고, Rocky Linux에 설치·서비스 등록·초기 보안 설정한 뒤, 실습 내내 쓸 employees 데이터베이스를 로드한다.

## What you will learn

- MariaDB의 성격(MySQL에서 fork된 오픈소스 RDBMS)과 dnf·systemd 기반 설치·서비스 관리
- `mariadb-secure-installation`으로 잡는 초기 보안(익명 사용자·원격 root·test DB)
- root 접속과 버전 확인
- employees 데이터베이스 로드(약 390만 행)와 규모 확인
