# 08 운영 엔지니어링 / 04 클라우드 관리형 DB

시리즈 전체를 닫는 캡스톤. 온프레미스·EC2·관리형의 책임 스펙트럼을 잡고, 이 시리즈에서 손으로 배운 모든 것을 "클라우드가 자동화하는 것 vs 여전히 내 책임"으로 회고 매핑한다. 자동화될수록 남는 것이 순수 엔지니어링임을 확인하며 관통선을 봉인한다. (이론 전용)

## What you will learn

- 데이터베이스 운영 세 형태: 온프레미스 / IaaS self-managed / 관리형(RDS·Cloud SQL·Azure) 책임 스펙트럼
- 책임 공유 모델(AWS 공식 비교표): **애플리케이션 최적화만 세 형태 모두 고객**
- "쿼리 튜닝은 고객": RDS 원문 + 3사 병렬 — 자동화는 인프라·운영, 남는 것은 쿼리·설계
- ⭐ 시리즈 회고 매핑: 백업·복제·모니터링은 자동화 / 관계형·설계·성능·동시성·커넥션 풀은 내 책임
- 대시보드는 값을 수집·표시, 해석·처방은 엔지니어(Performance Insights 회수). 관리형의 대가(비용·제약·종속·블랙박스)
- 봉인: "손으로 해봤기에 무엇이 자동화되고 무엇이 내 책임인지 안다. 남는 것이 순수 엔지니어링"
