# 01 데이터와 데이터베이스 엔지니어링 / 02 Database Engineering이란

- 데이터베이스 엔지니어링의 정의와 데이터 엔지니어링과의 차이
- DA·DBA·App Dev 세 역할과 인프라 엔지니어가 매우는 갭
