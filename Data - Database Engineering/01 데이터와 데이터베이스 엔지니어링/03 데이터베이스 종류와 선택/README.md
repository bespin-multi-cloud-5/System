# 01 데이터와 데이터베이스 엔지니어링 / 03 데이터베이스 종류와 선택

관계형과 NoSQL의 차이와 고르는 기준을 보고, 이 시리즈가 관계형 데이터베이스와 MariaDB를 다루는 이유를 정리한다.

## What you will learn

- 관계형 데이터베이스의 특성(정형·스키마·SQL·ACID·수직 확장)
- NoSQL의 네 유형(Document·Key-Value·Wide-Column·Graph)
- 관계형과 NoSQL의 선택 기준(데이터 구조·관계·일관성·확장·워크로드)
- 이 시리즈가 관계형과 MariaDB를 선택한 이유
